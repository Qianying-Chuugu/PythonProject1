# 计算机网络笔记：TCP 与网络协议

## TCP 三次握手
1. 客户端发送 SYN 报文，请求建立连接。
2. 服务器回复 SYN + ACK，确认收到并同意连接。
3. 客户端再发送 ACK，连接建立完成。

为什么是三次不是两次？为了防止已失效的连接请求突然又传到服务器，产生错误连接。

## TCP 四次挥手
1. 客户端发送 FIN，请求断开。
2. 服务器回复 ACK，确认收到。
3. 服务器发送 FIN，也请求断开。
4. 客户端回复 ACK，连接释放。

挥手比握手多一次，因为 TCP 是半关闭的：一方断开后，另一方可能还有数据要发。

## 其他
IP 地址分为网络号和主机号，子网掩码用来划分子网。
HTTP 是无状态协议，HTTPS 在 HTTP 和 TCP 之间加了 TLS 加密层。
DNS 把域名解析成 IP 地址。
