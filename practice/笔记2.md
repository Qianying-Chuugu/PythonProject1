# 动态规划复习笔记

## 什么时候用动态规划？
1. 问题可以分解成重叠的子问题。
2. 存在最优子结构：问题的最优解包含子问题的最优解。

## 解题步骤
1. 定义状态：明确 dp 数组的含义。
2. 找状态转移方程：当前状态如何由之前状态推出来。
3. 初始化：确定边界和初始值。
4. 确定遍历顺序。
5. 返回结果。

## 经典题型
- 背包问题：0-1 背包、完全背包、多重背包。
- 最长递增子序列、最长公共子序列。
- 编辑距离、矩阵链相乘。
- 股票买卖问题（一系列）。

## 空间优化
很多 dp 只需要前一行或前几个状态，可以用滚动数组把 O(n^2) 降到 O(n)。
